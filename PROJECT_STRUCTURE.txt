================================================================================
                              PROJECT OVERVIEW
================================================================================

CSE Stock Insight is a mobile Android application designed for fundamental and
technical stock analysis focusing on Sri Lankan (CSE-style) companies. This is
an academic project developed for learning purposes with dummy data and demo
APIs - NOT for real trading.

================================================================================
                          TECHNOLOGIES & LANGUAGES
================================================================================

FRONT-END (Mobile Application)
-------------------------------
Language:           Java (100% - No Kotlin)
IDE:                Android Studio Otter | 2025.2.1
Build System:       Gradle 8.11.1
UI Framework:       XML Layouts + Material Design Components 3
Minimum SDK:        API 21 (Android 5.0 Lollipop)
Target SDK:         API 34 (Android 14)

UI Libraries:
  - Material Components: 1.6.1 (Material Design 3 UI elements)
  - ConstraintLayout: 2.1.4 (Flexible responsive layouts)
  - RecyclerView: 1.2.1 (Efficient list displays)
  - CardView: Built-in (Card-based design)

Chart/Graph Library:
  - MPAndroidChart: v3.1.0 (Bar charts, line charts, pie charts)

BACK-END (Local - No Remote Server)
------------------------------------
Database:           Room (SQLite wrapper)
Database Version:   Room 2.4.3
ORM:                Room Persistence Library
Database File:      company_database.db (local SQLite)

Data Management:
  - Room Runtime: 2.4.3
  - Room Compiler: 2.4.3 (Annotation processor)
  - SQLite: Built-in Android database

DATABASE STRUCTURE
------------------
Tables:
  1. users (Authentication data)
  2. company_fundamentals (Stock data)

Storage Type:       Local device storage (offline-first)
Data Format:        Relational database (normalized tables)

NETWORKING & APIs
-----------------
HTTP Client:        Retrofit 2.9.0
JSON Parser:        Gson 2.9.0 (converter-gson)
HTTP Engine:        OkHttp (bundled with Retrofit)

API Usage:          2 demo APIs (placeholders)
  - API 1: Stock price lookup
  - API 2: Currency conversion / Financial news

ADDITIONAL LIBRARIES
